# Spawn On Beach

**Spawn On Beach** is a mod for **Zumbi Blocks 2** that changes the initial spawn point and respawn points to a random position on the beach/coast part of the map.

## Installation

1. Make sure you have the latest version of **BepInEx 5** installed
2. Download the latest version of the mod from the [releases](https://github.com/tbv001/ZB2.SpawnOnBeach/releases) page
3. Copy the DLL file into the `plugins` folder of your BepInEx installation:

```
Zumbi Blocks 2 Open Alpha\BepInEx\plugins\SpawnOnBeach.dll
```
